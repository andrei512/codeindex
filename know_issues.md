# Known issues

The Django findings below were reproduced on SWE-bench Verified case `django__django-15629` at testbed commit `9b70bb1938e97614e57443bbade13b71730f813e` (the public Django base commit for the conformance fixture is `694cf458f16b8d340a3195244196980b2dec34fd`). Correctness fixes have a specific expected result. Quality decisions require agreement on what answer an agent should receive.

## Test classification

All 71 disagreements in the published role benchmark have been reviewed. The classifier recovered 66 against the original labels. The other five have documented Java label corrections. These cases are regression coverage for the supported profiles. Accuracy on unseen repositories requires a fresh evaluation. [Results and reproduction](benchmarks/test_roles/README.md)

## Repair results

The integrated comparison used release binaries, pinned source revisions and the public CLI. Across 137 cases covering 34 profiles, all 1,960 required fixture checks passed. Of those, 206 were failures on the identical baseline questions. The remaining ten original failures used incorrect Perl expectations. The fixture now asserts both the real call locations and the unresolved assignment variables at all three original positions. All 39 named-reference failures and all 78 required failures across the compiled, script and format sweeps recovered. No previously passing baseline question regressed.

Clang supplied 785 sampled questions across 14 pinned repositories. All 375 disputed answers recovered on the original sources. All 409 previously correct answers remained correct. The remaining symbol was present among 55 results for `main`. Of 193 previously missing reverse witnesses, 191 appeared directly and two fell beyond the public 50-hit cap in an 84-reference list. A cap-only test reader found all three hidden locations on the published snapshots and confirmed the exact first 50 results for each query. The TypeScript language service comparison recovered all 27 misbound uses.

Calling a parameter binds the written reference to its parameter declaration. A callers result requires a proven implementation target. The seven callable-parameter fixtures now require this behavior, including removal of old edges after edits. The documented coverage probes for dynamic or unsupported forms remain separate from correctness totals. The ranking and Linux query-latency observations below remain open.

When a configured C or C++ query depends on an external SDK header, the index records the evidence used to select the active branch. A change to that header or creation of a higher-priority header invalidates the affected translation units even if the checkout stays untouched. In a separate Clang comparison of 545 SDK macro conditions without explicit SDK paths, 39 answers matched, 506 remained unknown and none chose the wrong branch.

On the 242-file public `kostya/benchmarks` checkout at `5bc68b3`, 13 alternating pairs compared the frozen binary with repair revision `847bbfc`. Cold fresh-build medians were 35.96 and 35.82 ms, with a paired ratio of 0.997 and a 95% bootstrap interval of 0.976–1.004. Warm fresh builds took 37.25 and 36.81 ms. Warm single-file edits took 29.47 and 29.15 ms.

**Configured C++ has a measured regression.** On LodePNG with explicit Apple SDK include paths, 13 alternating warm-source pairs measured fresh builds at 38.89 ms before and 127.78 ms after. Unchanged standalone lookups rose from 4.13 to 7.41 ms. A cold index now reads the reachable system headers to establish which macros they can change. Reopening verifies that the evidence still holds. These measurements include CLI startup and durable publication on fresh builds.

## Original language suite findings

Reproduce with `cargo build --release --locked` and `python3 tests/language_conformance.py --public`. Add `--language PROFILE` to isolate a lowercase profile. The JSON report names the source position, missing or unexpected locations, and build phase. A missing forward edge can also fail references and callers across several phases.

- **C++.** The declaration parser drops a function returning a templated reference because it expects a word before the reference punctuation and encounters the closing angle bracket. The public robin-hood-hashing case loses the definition and 15 call sites. A separate overload fixture loses the target after switching to a string literal. Its argument classifier and stored parameter type do not distinguish the pointer overload. [C-family parser](src/domain/code/cfamily.rs)
- **C#.** In Humanizer, the overload resolver lacks an argument type for the nested `input.AsSpan()` expression. The call to the span overload of `FromRoman` is unresolved. [Public case](tests/fixtures/languages/csharp/public-humanizer/checks.tsv)
- **TypeScript.** A declaration-file signature without an implementation is filtered as an overload. In a separate case the parser omits the TypeScript namespace and loses the call to its exported member. Both targets were checked with the TypeScript language service. [TypeScript cases](tests/fixtures/languages/js)
- **Kotlin.** A call inside an `init` block loses its enclosing class during lookup. A private method called there has no incoming reference. [Public case](tests/fixtures/languages/kotlin/public-benchmarks/checks.tsv)
- **Lua.** The resolver restricts local function bindings to top level and lets a disjoint same-name declaration suppress an earlier valid use. [Scope fixture](tests/fixtures/languages/lua/lexical_function)
- **Mako.** Bare calls to the local template def `makerow` disappear because expression capture requires a `local.` prefix. Mako's generated Python binds both calls to that definition. [Template parser](src/domain/code/extended/scripts/mako.rs)
- **Objective-C.** The selector parser skips trailing attributes only on selectors with arguments. A zero-argument method bearing `objc_direct` disappears, together with the direct self-message that targets it. Clang recognizes the declarations. [Selector fixture](tests/fixtures/languages/objectivec/direct_selector)
- **Perl.** A subroutine with a signature has a searchable name, but binding registration expects an opening brace immediately after that name. Three calls to that subroutine in the public case lose their target. [Perl resolver](src/domain/code/extended/scripts/perl.rs)
- **PHP.** Lookup checks whether a name is unique before narrowing it to the caller's namespace. A same-name function in another namespace suppresses the correct local binding. [Namespace fixture](tests/fixtures/languages/php/namespace_function)
- **PowerShell.** Ordinary command invocation has no parentheses. Generic call capture requires them, so a declared function can be searchable while its actual invocations disappear. [Command fixture](tests/fixtures/languages/powershell/command_case)
- **Python.** The public Django and synthetic inheritance cases reproduce the missing `super()` edge described above. The edited fixture changes the base class and checks both directions again. [Inheritance fixture](tests/fixtures/languages/python/super_call)

**Documented coverage limit.** Ruby's resolver records explicit singleton calls. The bare call to the top-level `generate_trie` function in the public case falls outside that scope. The suite reports it as a coverage probe.

### Second discovery pass

These synthetic cases test where a name is visible and which parts of a file contain executable code. Each links to the labelled input that distinguishes the expected answer from a plausible wrong answer.

- **Go, Kotlin and Dart lose a valid call after a block ends.** The shared resolver remembers a local name for the entire method. Rename only the integer inside the closed block and the untouched call resolves again in all three languages. [Go fixture](tests/fixtures/languages/go/discovery_callable_shadow) · [Shared resolver](src/domain/code/extended/objects.rs)
- **Java misses a call to a parent method.** The child overrides `emit`. The explicit `this.emit()` call resolves, but `super.emit()` loses the parent definition and reverse reference. The explicit-receiver path omits `super`. [Java fixture](tests/fixtures/languages/java/discovery_super_receiver)
- **Objective-C misses an explicit direct self-message.** The shadow-name check treats a selector component followed by a colon as a local name. Clang emits a direct call to the instance method even with a same-name class method present. [Objective-C fixture](tests/fixtures/languages/objectivec/discovery_method_kind)
- **PowerShell indexes a function inside a block comment.** Line comment handling resumes scanning after the first newline inside `<# … #>`. The result includes a declaration from comment text. [PowerShell fixture](tests/fixtures/languages/powershell/discovery_block_comment)
- **Ruby misses a literal singleton call without parentheses.** MRI invokes the expected method. The resolver requires an opening parenthesis to record the call site. Both definition and reverse reference disappear. [Ruby fixture](tests/fixtures/languages/ruby/discovery_embedded_document)
- **Terraform misses interpolation in a heredoc.** Terraform expands `${var.zone}` and preserves the escaped `$${var.zone}` as text. Codeindex treats the entire heredoc as opaque, losing the real forward and reverse edge. [HCL fixture](tests/fixtures/languages/hcl/discovery_heredoc_template)
- **Procfile omits hyphenated process names.** Foreman recognizes both `release-task` and `worker`. The Codeindex name scanner accepts only letters, digits and underscores. [Procfile fixture](tests/fixtures/languages/procfile/discovery_hyphenated_process)

**Named reference lookup.** Thirty ambiguous names correctly produce an ambiguity error, then recommend a command whose output omits the byte column required to select a declaration. Two other ambiguous lookups fail earlier because the symbol index misses declarations. For seven unique names, the by-name and positional lookups miss the same expected references. [Named-reference audit](tests/language_named_references.py)

**Semantics at discovery time.** Several languages distinguish the variable used in a call from the implementation invoked at runtime. The callable-parameter fixtures mark navigation to the lexical parameter as a probe until the query contract is settled. Their ordinary direct-call and same-name exclusion checks have exact answers. A separate Hack probe records an unresolved literal class-qualified call.

### Follow-up discovery waves

- **Swift, C++ and C# can index declarations from inside strings.** The shared lexer ends these strings at an ordinary quote. The tested C++ raw delimiter, Swift hash delimiter and C# triple delimiter keep that quote inside the string. Swift also leaks a fake function from a nested block comment because it treats the first closing delimiter as the end of the outer comment. [Compiled fixtures](tests/language_compiled_sweeps.py)
- **Taking a function as a value can suppress a later direct call.** In the Go case, assigning `seek` to a local variable before calling `seek()` loses the real call. The same shadow-name collector produces misses in Java, Kotlin, Dart and Objective-C. This is a new trigger for the existing shadow-scope issue. [Shared resolver](src/domain/code/extended/objects.rs)
- **Batch misses calls after a command separator.** The parser examines only the first command on a line. Two valid `call :alpha` commands after an `echo` both disappear. **Ruby loses singleton calls after a class is reopened.** Repeating the class declaration marks its name as reassigned. MRI calls both methods on the reopened class. [Script fixtures](tests/language_script_sweeps.py)
- **PowerShell can report the wrong function.** A module-qualified call and a bare call can target two distinct same-name functions. PowerShell executes the imported one for the qualified spelling and the local one for the bare spelling. The same-file lookup attaches both to the local declaration. This creates a false reference to the local function. A separate control isolates case folding: `alpha (1)` resolves, but `ALPHA (1)` does not, although PowerShell invokes the same local function for both. [Module fixtures](tests/language_script_sweeps.py)
- **Assembly drops dotted labels.** The assembler accepts `helper.internal` and emits that symbol, while Codeindex loses its declaration and its direct call. **HTML indexes markup inside iframe fallback text.** The HTML parser treats that content as text, while Codeindex emits an ID from an apparent inner element. [Format fixtures](tests/language_format_sweeps.py)

### Public compiler comparisons

- **C function declarations.** A lowercase annotation macro before a function name and a lowercase typedef used as a return type can each suppress the declaration. A control that changes only the triggering construct restores lookup. NanoPB and cJSON contain real instances. [C fixtures](tests/fixtures/languages/c)
- **C binding and preprocessing.** A prior prototype for the same function can make a later direct call unresolved even when the file contains one definition. Removing only the prototype restores both navigation directions. A declaration under a true, locally defined `#if PRESENT` can disappear. Replacing the condition with `#if 1` restores it. [Prototype fixture](tests/fixtures/languages/c/wave_clang_forward_declaration) · [Conditional fixture](tests/fixtures/languages/c/wave_clang_conditional_define)
- **C++ function declarations.** Numeric digit separators can consume subsequent code as if they opened a character literal. A legal method named `get` is filtered by a keyword rule shared with C#. An out-of-class definition such as `void Sample::reset()` can disappear even though Clang recognizes it. Each has a separate preserving control. [C++ fixtures](tests/fixtures/languages/cpp)
- **JavaScript anonymous-function parameters.** A capture rule expects an identifier after `function`. In `function (value) { … }`, the inner parameter can disappear, the inner use resolve to an outer variable and the outer reverse-reference list acquire a false hit. A named function expression and an arrow function are controls. [Scope fixture](tests/fixtures/languages/js/wave_anonymous_parameter)

A further residual sample exposed C++ misses for a receiver directly initialized with parentheses, a method called on a temporary, and a helper inside an anonymous namespace. Brace initialization, a named receiver and a file-static equivalent are independent controls. [Initialization fixture](tests/fixtures/languages/cpp/wave_clang_direct_initialized_receiver) · [Namespace fixture](tests/fixtures/languages/cpp/wave_clang_anonymous_namespace)

Across 14 pinned C/C++ repositories, Clang supplied 785 sampled questions. Codeindex answered 409 as expected, disagreed on 375, and capped the result for one. Two source interventions recovered 47 of 48 disputed LodePNG answers and 24 of 30 disputed C++ primes answers. Separate single-definition edits in NanoPB and cJSON recovered 89 of 146 disagreements from the original sample. These 160 recoveries concern distinct original rows. Other mismatches require their own causal evidence. [Public Clang oracle](tests/language_compiled_oracle.py) · [Paired C controls](tests/language_c_residual_controls.py)

The remaining Clang discrepancies were ranked by a hash of their locations and sampled separately per repository and operation. In six batches, 92 of 103 sampled mismatches recovered under controls that preserved Clang's declaration and binding locations. Eleven remained unattributed in that audit. Newly isolated triggers per batch were 2, 1, 1, 0, 0 and 0. Of the 44 sites in the final three batches, 39 recovered using established controls. Counting unique original queries by translation unit, operation, subject and expected location across all three intervention reports gives 241 of 375 with an observed recovery. The other 134 lack a verified causal intervention. A separate minimized case confirms that C++ overloads distinguished by method constness can lose a direct call through a nonconst receiver. Renaming only the const overload restores navigation. The real source that prompted the test also has out-of-class definitions, so its failure still has multiple possible causes. [Ranked residual controls](tests/language_compiled_residuals.py) · [Const overload case](tests/fixtures/languages/cpp/wave_clang_const_method_overload)

For the 375 sampled C/C++ call sites, the reverse audit found 193 missing references. Every one also failed forward navigation. No sampled call with a correct forward answer lost its reverse edge. This audit checks independently identified direct calls with a written target in the same translation unit. [Reverse witness](tests/language_reverse_witness.py)

**Observed return from additional tests.** The active conformance cases and synthetic sweeps reproduce required discrepancies in 22 of 34 profiles. The TypeScript public lexical batches found 5, 11, 8, 3 and 0 mismatched sites. All 27 are anonymous-function parameter uses. The first batch added a cause and the next four repeated it. The 510 repository-transition assertions, 120 independent HTML ID checks, and the three Django declaration/direct-call samples produced no new cause. These are separate populations with different questions. Per-query failures and files excluded by each oracle remain available in the corresponding report.

## Performance

**An explicit-file search on Linux pays repository-wide freshness costs.** With the same literal over 12 warm trials, median single-file latency was 117 ms for `cx` and 76 ms for `rg`. The instrumented `cx` spent 97 ms in refresh, including 40 ms reopening the snapshot and 54 ms observing 6,629 paths. Query evaluation took 8.5 ms. Across the Django source tree, the corresponding medians were 135 ms for `cx` and 193 ms for `rg`.

The acceptance check is a paired same-literal benchmark at increasing scopes plus an edit immediately before the next query. The test build that skipped observation missed the newly appended line. Any optimization must preserve visibility of edits. [Refresh path](src/adapters/snapshot/store.rs) · [Watcher availability](src/adapters/watcher/mod.rs)
