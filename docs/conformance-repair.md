# Repairing the conformance findings

This is the team execution plan for the defects recorded in the [findings ledger](../know_issues.md) and the discovery reports. The coordinator owns every discrepancy through verification. A single parser defect can break symbol search, forward navigation, references and callers across multiple build phases. Assign the first incorrect fact once and use all downstream failures to verify the repair.

## Coordinate the agents

1. **Freeze the comparison.** The coordinator records the baseline revision, binary, platform, oracle versions, pinned checkouts and report commands. Preserve the original JSON outside tracked files before rerunning a command that overwrites it. Key each question by suite, fixture or pinned file, phase, operation, subject and expected locations. Track every row as correct, required discrepancy, coverage probe, capped or unverified. Mark missing commands and unavailable oracles explicitly.
2. **Dispatch from the entire queue below.** Start the JS binding, object scope, and C-family declaration owners in separate worktrees. One coordinator and three workers can operate concurrently. Refill each slot as soon as a change is ready for review. An owner is a role that can pass between agents. Only one agent edits a shared module at a time. Other agents can minimize cases, verify public evidence or work in disjoint modules immediately.
3. **Give each patch a concrete handoff.** Record the failing command, expected target, nearest plausible wrong target, source module, independent witness, dependent assignments and exact checks. Keep the Rust production fix with the fact producer. Compilers and language services run in tests. Additional passes, persisted fields or allocations need a query consumer and a measured cost.
4. **Review, merge, recompare.** A second agent challenges the patch with a same-name decoy, a syntax boundary or an edit that invalidates the old target. The coordinator runs affected checks on the combined branch and updates the ledger with the commit, recovered rows and any regressions. Reassign remaining rows until each has a verified disposition.

## Assign the repairs

Each numbered assignment has its own acceptance check. Agents can submit individual causes independently.

1. **JS and TypeScript binding.** In the script parser, capture anonymous-function parameters in their inner scope, retain ambient declarations without implementations, and bind namespace members. Check the outer variable receives no inner references, keep named-function and arrow controls, and rerun the public TypeScript service comparison including all 27 previously misbound uses. Recheck the ambiguous declaration lookup for `escapeStringRegexp`.
2. **Python inheritance.** Resolve the plain single-inheritance `super().method()` fixture. Switch its base class and verify that the old reverse edge disappears and the new one appears. Rerun the pinned Django call and same-name decoy. Coordinate shared script-resolver edits with assignment 1.
3. **Object-language scope.** In the shared object resolver, bound shadows by lexical block in Go, Kotlin and Dart. Distinguish a function used as a value from a new shadow in Go, Java, Kotlin, Dart and Objective-C. Verify the value use, the later call and the reverse list separately. Then restore class ownership inside Kotlin initializers, bind explicit Java `super` to the parent, and narrow PHP functions by namespace before testing uniqueness.
4. **Objective-C selectors.** Capture a zero-argument selector with a trailing attribute. Distinguish a selector component from a local declaration. Use Clang to check same-name class and instance methods, direct self-messages and the formerly incomplete ambiguous `emit` lookup. Coordinate writes with assignment 3.
5. **Lexer boundaries.** Handle C++ raw strings and numeric separators, C# triple-quoted strings, Swift hash-delimited strings and nested comments, and PowerShell multiline comments. For each syntax, hide a fake declaration inside it and retain the real declaration immediately after it. Rerun the compiled and script boundary fixtures. One owner integrates shared lexer changes.
6. **C-family declarations and preprocessing.** Recover C annotation/calling-convention macros and typedef return types, C++ templated values and references, contextual method name `get`, and out-of-class definitions. Reproduce conditional visibility under the actual compiler configuration, including local defines and tested public feature guards. Exercise active and inactive branches and a configuration edit. Use the NanoPB, cJSON, LodePNG and C++ public intervention reports to check the original code with the fix.
7. **C-family binding.** Unify a C prototype with its definition. Handle C++ string/pointer overloads, const versus nonconst methods, parenthesized direct initialization, calls on temporaries and anonymous namespaces. In C#, handle the nested `AsSpan()` overload fixture. Check competing overloads explicitly. Sequence edits to the shared C-family module with assignment 6 and replay against the repaired declaration set.
8. **PowerShell commands.** Capture ordinary command invocation, apply case-insensitive binding, and distinguish module-qualified calls from an identically named local function. Check bare, qualified, redirected, removed and restored modules. Check callers, references and absence of an invented local edge when the module disappears.
9. **Script bindings.** Repair Lua local-function visibility across disjoint scopes, Mako bare calls to local template definitions, Perl subs with signatures, and Ruby singleton calls without parentheses and after class reopening. Use the labelled fixtures and runtime or generated-code witnesses. Verify each target and the absence of decoy bindings.
10. **Formats and command boundaries.** Handle Batch calls after separators, assembly dotted labels, hyphenated Procfile names, real HCL heredoc interpolation and HTML iframe fallback text. Check both calls on one Batch line, the exact assembler symbol, escaped HCL interpolation, and real HTML IDs adjacent to fallback content. Run the corresponding script and format sweeps.
11. **CLI name lookup.** Make ambiguous-name advice print a runnable command that supplies the required column. Follow it with duplicate names and a multibyte prefix. Recheck all 30 diagnostic cases, the two ambiguities dependent on declaration repairs, and seven unique names with missing references. For the 40 unpaired cases, supply an independently labelled comparison where applicable or record why the comparison cannot be made.
12. **Unattributed failures.** An independent evidence owner starts with all 785 pinned Clang questions. There were 409 correct, 375 disputed and one capped. Interventions recovered 241 disputed rows on modified inputs. Recheck the original input for every row after merging the fixes. Minimize each surviving discrepancy, keeping Clang’s expected binding fixed. Route each new cause to its producer. Establish membership for the capped answer through paging or an uncapped test witness and verify the public cap separately. Recheck the 193 missing reverse edges with the forward results. Investigate reverse construction wherever a correct forward edge still lacks its reverse.

## Decisions and performance

Use the language's binding rules for correctness decisions. A change in ranking, displayed context or another product preference needs concrete examples for review.

- **Navigation coverage.** A call through a parameter navigates to its lexical declaration. The parameter's references include that invocation. An implementation's callers include the site only when binding proves that implementation was called. C, C++, C#, Dart, Go, Kotlin and Swift each exercise this rule across fresh and edited indexes. Separately decide how to expose Python runtime dispatch, a literal Hack class-qualified call, Ruby top-level calls, and the cross-file module probes in PHP, Hack, Ruby, Lua and Perl. For each, show exact CLI output for a known target, plausible target, unrelated same-name target and unavailable dependency. Turn the agreed behavior into assertions and assign implementation to the corresponding language owner.
- **Ranked retrieval.** Show the passage for Django’s foreign-key collation question and its rank for the broad query and identifier query. Agree on a labelled set of issue-language questions and relevance criteria before trying ranking changes. Measure rank and preservation of exact-name results. Keep the 426 BM25 arithmetic comparisons as controls.
- **Ranked excerpts.** On identical ranked passages, compare the current line, a rarity-aware line and a short excerpt. Show the user the text, bytes and extra reads each requires. Apply the agreed display rule independently of retrieval scoring. Use paired Terminal-Bench trials if claiming an agent token or cost improvement.
- **Linux explicit-file latency.** The freshness owner repeats the paired single-file, directory and repository measurements with the same queries and cache conditions. Separate reopen, filesystem observation and matching. Test an edit immediately before a query with an active watcher and with no watcher. Report distributions and freshness failures. Adopt a faster path only if it observes the edit and preserves the search contract.

## Close the work

- **Per patch.** Exercise fresh, reopened and edited indexes against independent expected answers. Compare the edited result with a clean rebuild, including removal of stale reverse edges. Run the affected Nx fixtures and the named public oracle or sweep that produced the failure. Nx’s PR target covers synthetic fixtures. Public and standalone evidence requires its own invocation.
- **Across binary upgrades.** The coordinator owns snapshot compatibility. For changed persisted facts, build an index with the baseline binary, leave the checkout untouched, open it with the repaired binary and compare with a clean repaired build. Update the relevant compatibility rules and measure the rebuild or reuse cost.
- **On the merged revision.** Run the full public discovery command from the [conformance guide](conformance.md), the paired C intervention and compiled residual scripts, and inspect the reverse witnesses emitted by the compiled oracle. Preserve the 12 profiles without recorded required discrepancies as controls, along with path routing, repository transitions, HTML ID and Django passing samples. Compare fresh build, edit and query performance on fixed inputs.
- **Report to the user.** Give counts of recovered required rows, newly wrong rows, remaining failures, capped answers, unverified cases and decisions awaiting approval. Show before/after query evidence and point to each fix. Close a cause only when its original query and its controls pass. Close the overall repair effort when every baseline row is accounted for, every agreed required behavior passes and no merged regression remains. Passing the sampled questions establishes the coverage exercised by those questions.
